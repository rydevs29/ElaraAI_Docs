## 📌 Tentang Elara AI

**Elara AI** adalah ekosistem kecerdasan buatan multi-layer yang dirancang dan dikembangkan sepenuhnya oleh **RifqyDev** dari Indonesia. Platform ini mengintegrasikan mesin inferensi dinamis berkecepatan tinggi, perayapan web waktu nyata (*Omni-Search*), memori jangka panjang otonom, pemrosesan multimodal (teks, gambar, audio, dan dokumen), serta gerbang pengembang (*Developer API Gateway*) yang kompatibel dengan standar integrasi internasional.

Sistem ini dirancang tanpa ketergantungan kaku pada satu jalur pemrosesan, melainkan memanfaatkan **Multi-Layer Failover Engine** untuk memastikan ketersediaan layanan hingga 99.9%.

## ✨ Fitur Utama

### 🧠 1. Multi-Layer Core Engine & Kasta Berjenjang
* **Dynamic Intelligence Classifier**: Otomatis menganalisis beban kueri (*Light, Medium, Complex, Ultra-Deep*) dan mengarahkannya ke sub-mesin paling efisien.
* **Tiering System (Kasta)**:
  * **🟢 Neon (Gratis)**: Akses ke model dasar berkecepatan tinggi dan jatah pencarian web harian.
  * **🔵 Plasma (Pro)**: Akses ke model penalaran menengah, pencarian mendalam, dan kuota unggah berkas lebih tinggi.
  * **🟣 Supernova (Dewa)**: Akses penuh tanpa batas ke mesin penalaran ekstrem, analisis visual/video, dan performa komputasi tertinggi.

### 🌐 2. Mega Omni-Search Engine
* **Fast Mode**: Pencarian kilat berlatensi rendah untuk verifikasi fakta instan.
* **Deep Research**: Menganalisis dan merangkum hingga 30+ sumber referensi web secara simultan.
* **Smart Auto-Trigger**: Otomatis mendeteksi kueri yang membutuhkan data waktu nyata (berita, cuaca, jadwal, data terkini) dan menyertakan sitasi tautan yang dapat diverifikasi.

### 👁️ 3. Pemrosesan Multimodal & Dokumen
* Mampu menganalisis berkas gambar, dokumen PDF, teks kode pemrograman, hingga audio secara langsung.
* Dilengkapi pembatasan kuota unggahan aman berbasis level kasta pengguna.

### 💾 4. Autonomous Long-Term Memory
* Elara secara mandiri mendeteksi informasi penting mengenai pengguna (nama, preferensi, pekerjaan, alur kerja) melalui tag memori terenkripsi dan mengingatnya di setiap sesi percakapan baru.
* Pengguna memiliki kontrol penuh untuk melihat dan menghapus memori melalui panel pengaturan.

### 🔌 5. Developer API Gateway (OpenAI-Compatible)
* Menyediakan endpoint publik `api/v1/completions` yang kompatibel dengan pustaka SDK standar (Python, Node.js, PHP, cURL).
* Dilengkapi dashboard manajemen API Key (`elara-sk-...`), kuota *Action Cost*, dan *Interactive Playground*.

### 🔄 6. Sinkronisasi Omni-Channel (Web, Android APK, Telegram)
* Sinkronisasi kasta dan akun tanpa login ulang menggunakan **Kode Pairing Teks Unik**:
  * **Elara Android APK**: Memasukkan kode sinkronisasi aplikasi langsung di ponsel.
  * **Telegram Bot**: Menghubungkan paket pengguna cukup dengan mengetik perintah `/connect <KODE>` di bot Telegram.

### 🧊 7. Cooling Recovery & Action Cost
* Sistem kuota adil berbasis poin komputasi (*Action Cost*) yang pulih secara otomatis sebesar 1% setiap menit saat sistem dalam keadaan istirahat (*idle*).
